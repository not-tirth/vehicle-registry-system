# Vehicle Registry System in C++

## Project Overview
Develop a Vehicle Registry System using C++ that demonstrates all types of inheritance and
encapsulation. The system will allow users to manage a registry of different types of vehicles.

## Concepts Used
- Classes and Objects
- Inheritance
- Single Inheritance
- Multilevel Inheritance
- Multiple Inheritance
- Static Data Members
- `switch-case` Statement
- While Loop 

## Technologies Used
- Programming Language: C++
- Header Files: `<iostream>`
- Compiler: GCC / MinGW

## Conclusion
This project demonstrates how inheritance and other OOP concepts can be used to organize different types of vehicles into a class hierarchy. The menu-driven interface allows users to enter vehicle details and track the total number of vehicles added to the registry
